Before you attempt any of these optional extra exercises, make sure you completed all the coding and tasks in the Sketches : Core notes!

These are optional exercises for those of you who would like a bit more of a challenge. Have fun!

Different Shapes

Create a new sketch that draws a picture made up of some simple shapes.

See if you can use more shapes than just rectangles and circles and use a range of colour and line styles to draw something simple - maybe a simple character like this 👉?

Use the Processing Reference documentation to find and use at least one command that we have not yet introduced or mentioned.



Moving Sign

Modify your underground sketch so that it moves or changes size in response to the mouse.

Hint: As with the core tasks you will need to use mouseX and mouseY but this time you may need to add or subtract numbers from these values to draw some of the shapes in the right place.
