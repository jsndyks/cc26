Remote Desktop

If you want or need to access Processing through a browser, the best way to do so is possibly through the University's remote desktop - CVD.

We show you how to connect here.

1. Access the Remote Desktop

You can log into the City University desktop, and use most of the applications, including Processing, through a virtual desktop that you can access via your browser:

  • https://city.ac.uk/cvd

Click the 'Desktop' logo and log in with your University credentials.

2. Use Apps Anywhere

Now run apps like Processing from this virtual desktop through the Apps Anywhere facility:

  • https://appsanywhere.city.ac.uk/

Search for Processing and when you find it, click ‘Start’

3. Use Processing

Processing should start and you can write, edit and copy code into it in the way that you would if you were running Processing on your local machine.

Be sure to save your sketches in a ‘Processing’ folder and manage your Processing portfolio on GitHub.
