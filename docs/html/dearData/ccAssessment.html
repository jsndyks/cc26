Assessment : Dear Data 100

This page outlines the the assessed assignment through which you will receive marks for #CreativeCoding and credit for the Java Programming module.

It describes the requirements - the constraints that you need to operate under, the things that you need to do; and the marking criteria - the features for which marks will be awarded, the things that get you a good grade.

Your mark for Term 1 of Java module will be a combination of assignments that you are set for the #CreativeCoding (Dear Data 100) and Java Programming (Multiple Choice Quiz) components of the module, with equal weighting.

Requirements

The assessed assignment for #CreativeCoding requires that you ...

Create a Processing sketch
that depicts a data set that you have collected over time
that explores some aspect of the world
that is interesting to you
through at least 100 observations (data points)

Hopefully you will do so ...

in creative & expressive ways
that you are pleased with and
that helps you learn (a little) about yourself & the world around you

Marking Criteria

You will be assessed in two parts with 20% of the marks awarded for Part 1 and 80% for Part 2:

Part 1 : Week 05 - Progress Check-In

This will be an individual progress check with one our Teaching Assistants: 5 mins per student, 10 students per assessor per hour.

criterion task marks assignment marks pass
engagement 25 5 The student arrives for check-in on time with a working laptop and a Processing sketch loaded
coding 25 5 The student can describe the nature of a method and write a short method that returns a value
data 25 5 The student collected data items on a selected topic in light of the Dear Data 100 activity:
    1 mark per item - up to 25
github 25 5 The student has a GitHub repository containing Processing scripts and data, with evidence of regular updates:
     5 marks per commit made on separate days - up to 3 (=15)
    10 marks extra if commits are made in different weeks

Part 2 : Week 11 - Sketch Check-In

This will be a demo and discussion post sketch submission.
It will be an individual meeting with our Teaching Assistants: 5 mins per student, 10 students per assessor per hour.

criterion task marks assignment marks pass
engagement 25 20 The student arrives on time with a working laptop that is running a Processing sketch that is associated with a valid Moodle submission
data 25 20 The sketch shows 100 data items on a selected topic in light of the Dear Data 100 activity:
    0.25 marks per item - up to 25
creativity 25 20 The sketch involves some creativity - and the student is able to describe & justify this with reference to SCAMPER terminology
coding 25 20 The student has created a class and used instances of that class (objects) in the sketch to encode and display the data

Submission

A single submission wil be made, for Part 2, prior to the check-in.

Submission will be through Moodle and will make reference to your activity on GitHub.
